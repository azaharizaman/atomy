# Atomy-Q Seed Quotation Fixtures Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a one-off API command that generates canonical synthetic quotation PDFs plus a manifest, then make the petrochemical tenant seeder reuse those committed fixtures deterministically on every seed run.

**Architecture:** Keep the fixture system entirely inside the Atomy-Q API app. A shared quotation catalog defines stable business keys and deterministic quote content, a lightweight in-app PDF writer renders text-bearing PDFs without adding external packages, the generation command writes committed fixtures plus `manifest.json`, and `PetrochemicalTenantSeeder` copies those fixture PDFs into `storage/app/quote-submissions/` while persisting matching metadata.

**Tech Stack:** PHP 8.3, Laravel 12, Artisan commands, Eloquent seeders, JSON manifests, local filesystem storage, PHPUnit.

---

## Scope

- One-off fixture generator command for canonical seed quotation PDFs
- Repo-managed fixture directory under `apps/atomy-q/API/database/seed-data/quotations/`
- Deterministic manifest keyed by stable business keys
- Seeder integration that reuses canonical fixture files instead of faker-driven quote paths
- Focused tests for command generation and seeded quote reuse
- Documentation update in `IMPLEMENTATION_SUMMARY.md`

## Non-Goals

- Introducing a third-party PDF package
- Generalizing this into a shared cross-domain fixture framework
- Backward compatibility for old faker-based seeded quotation file paths
- Reworking unrelated factories that do not depend on these quote PDFs

```php
<?php

declare(strict_types=1);

namespace App\Support\SeedData\Quotations;

final class SeedQuotationManifest
{
    /**
     * @param array<string, array<string, mixed>> $entries
     */
    public static function write(string $path, array $entries): void
    {
        $payload = [
            'version' => 1,
            'entries' => $entries,
        ];

        file_put_contents($path, json_encode($payload, JSON_PRETTY_PRINT | JSON_UNESCAPED_SLASHES | JSON_THROW_ON_ERROR) . PHP_EOL);
    }

    /**
     * @return array<string, mixed>
     */
    public static function read(string $path): array
    {
        return json_decode((string) file_get_contents($path), true, 512, JSON_THROW_ON_ERROR);
    }
}
```

- [ ] **Step 4: Implement the minimal PDF writer**

```php
<?php

declare(strict_types=1);

namespace App\Support\SeedData\Quotations;

final class SimplePdfWriter
{
    /**
     * @param list<string> $lines
     */
    public function write(string $path, array $lines): void
    {
        $content = "BT\n/F1 12 Tf\n50 780 Td\n";

        foreach ($lines as $index => $line) {
            $escaped = str_replace(['\\', '(', ')'], ['\\\\', '\\(', '\\)'], $line);
            $content .= sprintf("0 -%d Td\n(%s) Tj\n", $index === 0 ? 0 : 16, $escaped);
        }

        $content .= "ET\n";

        file_put_contents($path, $this->wrapPdfObjects($content));
    }
}
```

Fill in `wrapPdfObjects()` with a valid deterministic single-page PDF object/xref layout.
