# Nexus Laravel Approval Operations Adapter

Laravel adapter package for Approval Operations orchestration ports.

## Package

- Composer: `azaharizaman/nexus-laravel-approval-operations-adapter`
- Namespace: `Nexus\Laravel\ApprovalOperations\`

## Installation

```bash
composer require azaharizaman/nexus-laravel-approval-operations-adapter
```

## Purpose

This package provides framework-specific implementations for Approval Operations integration in Laravel applications while keeping orchestration contracts framework-agnostic.
