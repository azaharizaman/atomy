# Nexus Laravel Sourcing Adapter

Laravel adapter package for Nexus Sourcing integration.

## Package

- Composer: `azaharizaman/nexus-laravel-sourcing-adapter`
- Namespace: `Nexus\Laravel\Sourcing\`

## Installation

```bash
composer require azaharizaman/nexus-laravel-sourcing-adapter
```

## Purpose

This package provides Laravel-specific sourcing adapters, including persistence and query integration points for sourcing workflows.
